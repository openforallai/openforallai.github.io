How far behind are open models?

The best closed, best open and best Korean model on each benchmark (best closed means the best one anyone can use; a closed model that has been announced but isn't public yet is shown on its own line where it would lead): the ones labs most often report, plus independent tests of agents doing real coding and real work. Scores are independent (Epoch AI and public leaderboards) wherever they exist; a maker's own number is used only where none does, and is marked *. Makers' own numbers tend to run higher than independent ones (Anthropic reports 60.9% on Humanity's Last Exam for Claude Fable 5.1; the independent leaderboard measured 46.5%), so a gap that mixes the two flatters the self-reported side.

How many months behind?

For each benchmark: when the best open model came out, against when a closed model first reached the same score. The lines are the best score so far on each side; each dot is a model, placed at its release date. Release date means when a closed model was first publicly available, or when an open model's weights went public. Only models in this table count: an older closed model that isn't listed may have got there earlier, which would make the real lag longer.
